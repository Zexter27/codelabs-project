## SOBRE EL PROYECTO

**Code Coffee** es un proyecto web inspirado en el concepto de una cafetería moderna que combina dos mundos: la cultura del café y la pasión por la tecnología.

La propuesta busca representar un espacio donde desarrolladores, estudiantes y amantes del café puedan encontrar una experiencia diferente, combinando una identidad visual relacionada con la programación y el ambiente acogedor de una cafetería.

El proyecto está desarrollado utilizando tecnologías fundamentales del desarrollo web.

## INSTALACIÓN Y EJECUCIÓN

Para ejecutar el proyecto localmente:

**1. Clonar el repositorio**

```bash
git clone https://github.com/Zexter27/codelabs-project.git
```

**2. Ingresar al directorio**

```bash
cd codelabs-project
```

**3. Abrir el proyecto**

Abre el archivo `index.html` directamente en tu navegador o utiliza la extensión Live Server de Visual Studio Code.

No se requiere una instalación de dependencias para la estructura HTML inicial.
